# 工具板夹爪接口

System 的 `EefApi` 和 SDK 的 `client.Robot()->Eef()` 提供工具板 RS485 夹爪接口。
目前 CanEvo 后端实现 EG2 普通串口协议，其他机械臂后端返回操作不支持。
配置中须给对应机械臂填写 `tool_id`，System 会复用该机械臂的 CAN 总线和周期步进。
这组接口通过 `ArmHal` 的工具板 RS485 访问 EG2 夹爪。

每次调用只需指定 `arm_name`，即 `client.Robot()->Model()->GetArmNames()` 返回的名称，例如 `modi_dm3_r`。
HAL 固定访问该臂 `tool_id` 列表中的第一块工具板，以及该板上 RS485 地址为 `1` 的夹爪。
SDK、System 服务和 Scope 请求均不再传递工具板下标或夹爪地址。

## 接口与返回值

| SDK 接口 | 含义 |
| --- | --- |
| GetToolGripperOpening | 读取实际开度，协议原始值 0~1000 |
| GetToolGripperTemperature | 读取驱动器温度，℃ |
| GetToolGripperFaultCode | 读取原始故障位图，可同时有多个故障 |
| GetToolGripperStatus | 读取运行状态 |
| SetToolGripperPosition | 设置目标开度的整数百分比 1~100，沿用已有速度和力度 |
| SetToolGripperCatch | 按速度百分比 1~100、力度 50~1000 g 夹取；可选择连续夹取 |
| SetToolGripperRelease | 按速度百分比 1~100 张开到最大开口 |
| SetToolGripperStop | 优先停止；只支持 true，可省略 |
| ClearToolGripperFault | 清除可恢复故障；过温须等待降温自动恢复 |

位置、速度入参统一为整数百分比，不传 `%` 字符：`50` 表示 `50%`。有效范围为 `1~100`，
`0`、超过 `100` 的旧原始参数均拒绝；停止请调用 Stop。HAL 下发前乘 10 转成 EG2 协议值，
Client/System 不再缩放；反馈开度仍为原始值 `0~1000`，显示百分比时除以 10。力度仍为 g。

服务路径为 `/Robot/Eef/<SDK接口名>`，使用现有 robot_id DDS 隔离。
所有方法返回 `int`：0 表示调用成功，非 0 保留 HAL、System 或 SDK 的具体错误码。
Get 方法通过引用参数输出单项数据，失败时保持调用方原值，不把读取失败误认为开度或故障值为零。
SDK 和 HAL 均只提供分项读取，不提供批量反馈函数或反馈结构体。页面由网关依次调用四个单项 Get；
任一项失败则返回错误，不输出不完整结果。各次读取之间可能发生缓存更新，不保证属于同一笔设备应答。
首次 Get 会登记地址以开始轮询；尚无回包或反馈超过 500 ms 时返回 `-402010`，调用方可稍后重试。

开度、夹取、松开要求系统允许运动（Safety=Normal、Robot=Running），并在 HAL owner 上再次检查。
停止、清故障和查询不要求机械臂处于 Running。所有夹爪访问在 HAL owner 上执行，避免与初始化、恢复并发。
这些调用不暂停 WBC，也不等待串口回包。HAL 不维护写指令 FIFO：

- 开度只保留一个最新待发目标，由周期步进发送；新目标覆盖尚未发送的旧目标。
- 停止独立优先，取消待发开度；重复停止请求合并。
- 夹取、松开、清故障只在通信空闲时直接发送；有待应答事务、待发目标或发送间隔未到时，返回 `-404003`（末端命令被拒绝），不保存动作。

控制成功不能据此认定动作已完成或故障已清除。失败不会自动重试运动指令，调用方须检查返回码。
反馈中的原始故障位图不转换为负数操作错误码。

## SDK 调用

```cpp
auto eef = client.Robot()->Eef();
std::uint16_t opening = 0;
const int ret = eef->GetToolGripperOpening("modi_dm3_r", opening);
if (ret == 0) {
  // opening 为协议原始开度 0~1000；温度、故障和状态分别使用对应 Get。
}
// 系统允许运动后，显式发送目标开度：
const int accepted = eef->SetToolGripperPosition("modi_dm3_r", 50);  // 50% 开度
// accepted == 0 表示最新目标已接收，随后读取反馈确认。
```

## 命令行示例

先启动 System，再在已加载工作空间环境的终端执行：

```bash
ros2 run modi_sdk single_arm_example_tool_gripper <robot_id> modi_dm3_r get
```

默认只读；控制必须显式指定操作：

```bash
ros2 run modi_sdk single_arm_example_tool_gripper <robot_id> modi_dm3_r position 50
ros2 run modi_sdk single_arm_example_tool_gripper <robot_id> modi_dm3_r catch 20 100
ros2 run modi_sdk single_arm_example_tool_gripper <robot_id> modi_dm3_r release 20
ros2 run modi_sdk single_arm_example_tool_gripper <robot_id> modi_dm3_r stop
ros2 run modi_sdk single_arm_example_tool_gripper <robot_id> modi_dm3_r clear
```

该接入增加显式夹爪服务调用，不会把原有关节 `ClearFaults` 自动变成夹爪清故障，
也不会把原有关节急停接口自动变成夹爪停止；夹爪须调用对应接口。
